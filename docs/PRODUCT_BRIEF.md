# 담타고고 제품 기획서 — 2-page 초안

## 1. 제품 정의

### 한 줄 설명

연초 또는 전자담배를 고르고 화면을 탭해 꺼내기, 점화, 흡입, 소진을 감각적으로 체험하는 iPhone용 인터랙티브 시뮬레이터.

### 목표

- 한 손으로 10초 안에 시작할 수 있는 짧고 직관적인 경험을 만든다.
- 제품 선택부터 소진까지 시각·햅틱 피드백이 끊김 없이 이어지게 한다.
- 담뱃갑과 기기 커스텀을 통해 반복 사용의 재미를 만든다.
- 화면 하단에는 플레이를 가리지 않는 적응형 배너 광고를 둔다.

### 핵심 원칙

1. 첫 화면에는 `연초`, `전자담배` 두 선택지만 보여준다.
2. 설명 문구는 최소화하고 오브젝트와 모션으로 사용법을 전달한다.
3. 배경은 검정 단색으로 유지한다.
4. 이미지는 사진처럼 사실적이지 않되 지나치게 단순하지 않은 스타일을 사용한다.
5. 탭마다 즉시 모션과 선택 가능한 햅틱 피드백을 제공한다.

### 핵심 사용자 흐름

```text
앱 실행
  ├─ 연초 → 담뱃갑 선택 → 한 개비 꺼내기 → 점화 → 탭으로 흡입/소진 → 잔량 감소
  └─ 전자담배 → 기기 선택 → 탭으로 흡입 → 연기/LED → 배터리·액상 감소
```

### MVP 기능

- 연초/전자담배 선택
- 담뱃갑 3종과 전자담배 1종
- 담배 꺼내기 및 점화 애니메이션
- 탭에 따른 길이 감소, 불씨와 연기 파티클
- 전자담배 LED 및 배터리 감소
- 잔량 로컬 저장
- 설정: 햅틱 진동 켜기/끄기
- 하단 AdMob 테스트 배너

## 2. 커스텀과 출시 범위

### 커스텀 기능 우선순위

#### 1차 — 출시 버전에 적합

- 담뱃갑 색상/디자인 선택
- 필터 색상 선택
- 라이터 불꽃 색상 선택
- 연기 양 `적음 / 보통 / 많음`
- 햅틱 진동 켜기/끄기

#### 2차 — 반응을 보고 추가

- 사용자가 색상 블록을 조합해 나만의 담뱃갑 만들기
- 담뱃갑에 짧은 별명 입력
- 전자담배 본체와 LED 색상 조합
- 배경 테마 및 소진 효과 선택
- 만든 디자인 저장 및 즐겨찾기

실제 담배 브랜드의 이름, 로고, 패키지는 출시 전 사용 권리와 앱스토어·광고 정책을 별도로 확인한다. 초기 버전은 브랜드가 없는 가상 패키지로 검증한다.

### 비주얼 결정 기준

- 현재 후보: 선이 또렷한 2D 일러스트 / 부드러운 2.5D / 픽셀 아트 / 구아슈 페인팅
- 추천 기준안: 선이 또렷한 2D 일러스트
- 확정 전에 확인할 상태 이미지:
  1. 닫힌 곽
  2. 열린 곽
  3. 담배가 반쯤 나온 곽
  4. 분리된 담배 한 개비
  5. 점화 전/점화/소진 상태

### 화면 구성

1. 홈: 설정 아이콘, 연초/전자담배 오브젝트와 짧은 라벨, 하단 광고
2. 제품 선택: 여러 곽 또는 기기를 가로 스크롤로 선택
3. 플레이: 중앙 오브젝트, 잔량 표시, 탭 영역, 하단 광고
4. 설정: 햅틱과 연기 양 조정

### 완료 기준

- 작은 iPhone에서도 오브젝트와 광고가 겹치지 않는다.
- 연초 한 개비가 처음부터 끝까지 최소 8회의 탭으로 소진된다.
- 앱을 다시 실행해도 담뱃갑·배터리 잔량과 설정이 유지된다.
- 모션 감소 접근성 설정과 햅틱 끄기를 지원한다.
- 출시 빌드에는 테스트 광고 ID가 남아 있지 않는다.

3. 가상 담뱃갑 3종의 색상 결정
4. 홈 및 플레이 화면에 최종 자산 적용
